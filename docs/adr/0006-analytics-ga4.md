# Analytics via Google Analytics 4

Traffic and referrer measurement uses Google Analytics 4. It is free, powerful, and ubiquitous, and we need visibility into whether pre-launch audience-building is working — the one metric the site exists to move right now.

Considered: privacy-first analytics (Plausible / self-hosted Umami) — rejected on cost/familiarity grounds despite being more on-brand.

Consequence: GA4 sets cookies, so the site must add a cookie-consent mechanism and a short privacy note (neither of which the privacy-first option would have required). Revisit if consent friction or script weight degrades the experience.
