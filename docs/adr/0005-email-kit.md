# Email capture via Kit (ConvertKit)

The newsletter signup (currently a mock that only changes the note text) will be wired to Kit (formerly ConvertKit) through an embedded form. Audience-building is the core pre-launch goal, and Kit is the author/creator-standard platform with the automations, sequences, and landing pages we'll want for an eventual launch — so we own and nurture the list from day one. It embeds with no backend, keeping the site static.

Considered: lighter platforms (Buttondown / MailerLite) and deferring capture into a raw list — rejected in favor of committing now to the platform we expect to grow into.

Consequence: an external dependency and account; Kit's free-tier limits apply as the list grows.
