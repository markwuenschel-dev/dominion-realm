# Site shape: cinematic homepage spine + deep subpages

The homepage stays a single-scroll cinematic "trailer"; each content pillar becomes its own rich subpage (`/codex`, `/read`, `/journal`, `/about`, alongside the existing `/eyes`), reached via the nav. This preserves the scroll-to-pitch experience that already works, gives unbounded room to grow a codex and journal, and serves both the immersive-experience and author-platform goals at once. The existing `eyes` page already demonstrates the pattern.

Considered and rejected: a portal/hub gateway landing (loses the linear, scroll-to-pitch storytelling) and a conventional multipage site (least distinctive, works against the immersive goal).
