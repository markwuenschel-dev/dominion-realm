# Dominion Realm — Story Bible Site

The public story bible and series companion for *Dominion Realm*, built with [Astro](https://astro.build) and hosted on GitHub Pages.

**Live site → [markwuenschel-dev.github.io/dominion-realm](https://markwuenschel-dev.github.io/dominion-realm/)**

---

## About

This site is the public face of the *Dominion Realm* canon — characters, world lore, the magic system, and series context. It is generated from a structured content layer and deployed automatically on push to `main`.

The novel manuscript and full working canon live in a separate private repository.

---

## Stack

- [Astro 6](https://astro.build) — static site framework
- GitHub Pages — hosting
- Content collections — structured canon data (characters, world, lore)

## Local Development

```bash
npm install
npm run dev
```

Preview at `http://localhost:4321`.

```bash
npm run build       # production build
npm run preview     # preview the build locally
```
